## Olá, eu sou o Danilo 👋

Engenheiro de Software com **5 anos de experiência** no setor financeiro, atuando de forma **full-cycle**: do discovery com stakeholders ao deploy em produção. Meu foco é construir **agentes e chatbots com IA** e **APIs em Python** que aguentam escala — guiadas por Clean Architecture, SOLID e TDD.

```yaml
localização:  Praia Grande – SP, Brasil
foco atual:   Apps SaaS · APIs · Agentes de IA
trabalhando:  Python (FastAPI/Flask) · TypeScript · AWS
princípios:   Clean Architecture · SOLID · TDD (90%+ de cobertura)
```

### 📌 Alguns resultados que entreguei

| Impacto | Contexto |
|---|---|
| **–60% de SLA** (20 → 8 dias) | Hub Retrofit 2.0 com integração ao PEGA System |
| **+50% de eficiência** | Programa interno de adoção de IA para times de dev |
| **Milhares de usuários** | Chatbot de IA corporativo — liderança técnica e desenvolvimento |
| **On-Premise → AWS** | Modernização de infra, mais escala e menos custo de manutenção |
| **Sistema portuário de Manaus** | E2E do zero à produção: OCR, Pix e automação de contêineres |
